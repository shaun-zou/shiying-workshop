        卷轴书斋 · 使用说明

        1. 壹
          研墨 · 选诗
          从内置诗库点选一首（会自动开始解析），或在输入框粘贴任意诗词后点「磨墨起笔」。此阶段只产出文本，不消耗生图与配音。
        2. 贰
          展卷 · 审核修改
          逐句释义、背景知识与故事文案均可点铅笔直接修改；句镜旁白与画面取自「逐句释义」，开场与收尾为故事文案。
        3. 叁
          调色 · 定风格音色
          九选一艺术风格（新中式水墨 / 工笔重彩 / 敦煌壁画 / 浮世绘等，AI 出图通道生效；svg 离线引擎固定水墨），再选朗诵音色与背景音乐，然后点「落墨 · 开始生成成片」。
        4. 肆
          作画 · 生成成片
          五道工序（文本 → 分镜 → 画面 → 声音 → 合成）实时推进。尾声镜不单独出图，画面与运镜直接复用最后一句镜。
        5. 伍
          钤印 · 预览导出
          下载成片 MP4、导出字幕 .srt、复制文案。成片后继续修改，回「展卷」点「应用修改并重新合成」（默认复用已出画面，只重做声音与合成；换艺术风格或勾选「重新生成意境图」会让画面全量重出）。

        快捷键：聚焦成片区后，空格 播放 / 暂停，← → 切换分镜。

        本页由本地服务（node src/cli.ts studio）驱动，成片为本机真实渲染，不经过任何外部服务。

        通道配置

        文本 / 生图 / 动效视频 / 声音四道 AI 通道在此集中管理：可新增任意 OpenAI 兼容节点并编辑接口地址、模型与密钥。优先级为「此处设置 → .env → 内置预设」；密钥仅保存在本机 data/studio-settings.json，保存后新任务即时生效，无需重启服务。

        作品库

          本地服务没有响应

          卷轴书斋需要通过诗影工坊的本地服务访问。请回到项目目录启动：

          npm run studio

          启动后刷新本页即可。若已启动，请确认端口未被占用（默认 7788，可用 --port 指定其他端口）。
