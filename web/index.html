        怎么用诗影工坊创作台

        1. 1
          选诗，先生成解析与文案
          从诗词库选择或粘贴任意诗词，点「生成解析与文案」。此阶段只产出文本，不消耗生图与配音。审核通过之前不会启动重成本环节。
        2. 2
          审核修改，定音色配乐
          逐句释义、背景知识与文案均可点铅笔直接修改；句镜旁白与画面取自「逐句释义」，开场与收尾为故事文案。在右侧选好朗诵音色与背景音乐。
        3. 3
          确认，开始生成成片
          点「开始生成成片」，依次执行：分镜意境图 → 朗诵配音 → 字幕烧制与合成。成片后继续修改，可点「重新合成」（复用已出画面，只重做声音与合成；勾选「重新生成意境图」可让画面按新文案全量重出）。
        4. 4
          预览与导出
          右侧预览真实成片：下载成片 MP4、导出字幕 .srt、复制文案。

        快捷键：聚焦预览区后，空格 播放 / 暂停，← → 切换分镜。

        本页由本地服务（node src/cli.ts studio）驱动，成片为本机真实渲染，不经过任何外部服务。

        本地服务没有响应

        创作台需要通过诗影工坊的本地服务访问。请回到项目目录启动：

        npm run studio

        启动后刷新本页即可。若已启动，请确认端口未被占用（默认 7788，可用 --port 指定其他端口）。
