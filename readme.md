# 诗影工坊 · 创作流水线（shiying-workshop）

> 从《诗影工坊》交互原型 V1 到真实产品的第一步：**输入一首诗 → 产出真实 MP4**。
> 按《技术扩展路书》第一步「跑通闭环」实现：文本 → 画面 → 声音 → 合成 四道工序，
> 本地零依赖运行（Node ≥ 22.18），离线可出片，接上真实服务即可升级质量。

---

## 30 秒上手

```bash
# 环境体检（FFmpeg / 浏览器 / 语音 / 各通道可达性）
node src/cli.ts check

# 列出内置诗词
node src/cli.ts list

# 跑通闭环：一键出片（默认离线通道：内置解析 + 水墨分镜 + 系统中文配音 + 原创配乐）
node src/cli.ts run --poem jingyesi

# 打开本地工作台（V2 网页面板，真实接口）
node src/cli.ts studio        # 然后访问 http://127.0.0.1:7788
```

> 无需 `npm install` —— 运行时零依赖，Node 22.18+ 直接执行 TypeScript。
> `npm install` 只装开发期类型检查器（`npm run typecheck`）。
> 启用神经语音配音（推荐）：`pip install edge-tts`（未装时自动回退系统语音）。

## 它长什么样

一件成品 = 一个 `output/job-<时间戳>/` 目录：

| 文件                | 说明                                                     |
| ----------------- | ------------------------------------------------------ |
| `video.mp4`       | 成片：1080×1920 竖屏 · 30fps · H.264 + AAC · 字幕烧制 · 旁白+配乐混音 |
| `subtitles.srt`   | 标准字幕文件（与 V1 原型导出同体系，可直接导入剪辑软件）                         |
| `subtitles.ass`   | 烧制用样式字幕（楷体诗句 + 雅黑旁白，可改字体/配色）                           |
| `cover.jpg`       | 封面帧                                                    |
| `scene-N.png/jpg` | 各分镜意境图（svg 引擎渲染 / AI 生成）                               |
| `narration.wav`   | 完整旁白轨                                                  |
| `analysis.json`   | 解析产物（释义/背景/文案，可编辑后重合成）                                 |
| `manifest.json`   | 任务清单（分镜时间轴、产用通道、文件清单）                                  |

## 四道工序与通道（Providers）

每一道工序都有多个「通道」可选，离线通道保证随时能出片，真实服务通道用于提升质量。

### ① 文本工序 —— 释义 / 背景 / 故事化文案

| 通道                            | 说明                                                        |
| ----------------------------- | --------------------------------------------------------- |
| `offline`（默认）                 | 内置三首诗的完整数据；任意诗词做结构解析，产出「纯朗诵版」                             |
| `glm` / `deepseek` / `openai` | OpenAI 兼容 chat/completions，JSON 结构化输出；未收录诗词也能生成释义、背景与故事文案 |

```bash
node src/cli.ts run --text "月落乌啼霜满天，江枫渔火对愁眠。" --text-provider glm
# 需先配置：SHIYING_TEXT_API_KEY（见 .env.example）
```

### ② 画面工序 —— 分镜意境图

| 通道         | 说明                                                                 |
| ---------- | ------------------------------------------------------------------ |
| `svg`（默认）  | 内置水墨分镜引擎（16 个场景构建器），无头浏览器截图，0 成本、风格可控                              |
| `seedream` | AutoGLM 本地通道（本机 AutoClaw 运行时免 Key 出真图；提供 `--crop-watermark` 裁水印选项） |
| `siliconflow` | 硅基流动图像接口 `Kwai-Kolors/Kolors`（OpenAI 兼容；9:16 竖版 720×1280；2026-10-07 实测已通、无平台水印） |
| `cogview`  | 智谱开放平台图像接口（按公开文档实现，需 API Key，未实测）      |
| `openai`   | OpenAI 兼容图像接口（需 API Key，未实测）                                       |

```bash
node src/cli.ts run --poem jingyesi --image seedream     # 真实 AI 意境图
node src/cli.ts run --poem jingyesi --image seedream --crop-watermark
```

> **Seedream 通道的「免 Key」机制**：AutoClaw 桌面端运行时在本机 `127.0.0.1:18432` 提供 token 服务（它持有你的平台授权态）。每次出图前，项目向它现取一个短时 Bearer 令牌，再按 AutoGLM 技能协议附加签名头（Appid 100003 + 时间戳 + MD5 签名，与官方技能脚本同款实现）调用网关；图片 URL 拿回后直接下载落盘。项目**不保存任何长期密钥，令牌不落盘**——所以仓库与配置文件里都没有 Key。因此该通道仅在 AutoClaw 运行中的本机可用（`check` 命令会检测其可达性）；网关侧出图带「AutoClaw AI生成」水印（平台行为）；要做产品化上云，请切换自备 Key 的官方开放平台通道（`cogview` / `siliconflow` 已就位；后者本机实测已通）。

> **旁白与画面的关系（提示词架构）**：分镜类型只提供「构图与氛围骨架」（不含具体物件）；句镜的**旁白、字幕与画面主体均取自「逐句释义」**（开场/收尾为故事文案）——修改释义后勾选「重新生成意境图」，画面即按新释义重出，不会残留与释义矛盾的元素。纯朗诵版（无释义）时以诗句本身为画面主体。
> 
> **人物一致性**：分析阶段根据情景判断诗句中的人物是否为同一人（如作者本人）——内置诗精修设定、自定义诗按关键词推断（接入大模型后由其判定）；同一人则生成一段「固定形象」描述并**逐字注入每一镜提示词**：涉及人物行为的句子要求该人物出现，写景句要求「如出现则形象一致」，保证多镜人物是同一张脸、同一身装束（可在工作台直接点击修改）。

### ③ 声音工序 —— 朗诵配音

| 通道         | 说明                                                                             |
| ---------- | ------------------------------------------------------------------------------ |
| `edge`（默认） | 微软 Edge 神经语音（真人感强、适合古诗朗诵；需 Python + `pip install edge-tts` + 联网；不可用时自动回退 sapi） |
| `sapi`     | Windows 本机语音（离线兜底）；单音色时通过音高塑形区分三档                                              |
| `openai`   | OpenAI 兼容 /audio/speech（需 API Key，未实测）                                         |
| `none`     | 不做配音（静默成片）                                                                     |

音色档案 → 神经语音映射：`yunque` 云阙·沉静男声 = **云健 Yunjian**（语速 −8%）· `qingzheng` 清徵·清亮女声 = **晓晓 Xiaoxiao**（−4%）· `songfeng` 松风·苍劲男声 = **云扬 Yunyang**（−12%）。工作台会显示当前「音色映射」。
**节奏控制**：分段合成 + 静音拼接（诗句与旁白之间 450ms 停顿、镜尾 750ms 留白），语速与停顿共同塑造吟诵感。

> Edge 神经语音免费、免 Key，但需联网；离线环境设 `SHIYING_VOICE_PROVIDER=sapi` 即可。产品化建议换官方云端语音（Azure / 火山引擎等，自备 Key）。

### ④ 合成工序 —— 成片

FFmpeg 单遍完成：逐镜运镜（zoompan 推近/拉远/横移）→ 拼接 → 烧制样式化字幕（libass）→ 旁白+配乐混音 → H.264 MP4（faststart）。
配乐为**程序合成原创音源**（`guqin` 古琴拨弦 Karplus-Strong / `rain` 雨声滤波噪声），无版权风险。

## 本地工作台（V2 创作台）

`node src/cli.ts studio` 启动后，浏览器访问 `http://127.0.0.1:7788`：

> 开发提示：修改 `src/` 下代码后，需**重启工作台服务**（停掉后重新 `npm run studio`）才会生效——Node 不做热加载；页面侧（`web/index.html`）的修改刷新浏览器即可。

生成采用**两段式（先审后产）**流程：

1. **生成解析与文案**（左栏）—— 只跑文本与分镜两道工序，不消耗生图/配音成本；
2. **审核修改 + 定音色配乐**（中栏 / 右栏）—— 逐句释义、背景与文案可逐条编辑（句镜旁白＝逐句释义，开场/收尾为故事文案）；音色与配乐此时选好；
3. **确认出片**（右栏「开始生成成片」）—— 依次执行：意境图 → 配音 → 字幕烧制与合成；
4. **迭代**—— 成片后继续修改，点「重新合成」会复用已出画面，只重做声音与合成；勾选「重新生成意境图」则忽略缓存与复用、按当前文案全量重出画面。
- **左栏**：诗词库 + 任意诗词输入 + 最近作品（历史任务回看）
- **中栏**：逐句释义 / 背景知识 / 文案 / 人物形象，全部可**行内编辑**（文案区的逐句旁白与释义同源，改一处两处同步；「人物」块编辑跨镜固定形象，勾选「重新生成意境图」后按新形象出图）
- **右栏**：审核确认块、真实成片播放（支持拖动）、分镜缩略图跳转、音色/配乐切换（含本机映射说明）、导出 MP4 / .srt / 文案
- 生成过程实时进度（五段流程条 + 总进度），SSE/轮询双通道

技术上：工作台由零依赖 Node HTTP 服务（`src/server.ts`）驱动 —— 任务 API（`mode: analyze | render`）+ 进度事件 + 媒体分发（含视频 Range 拖动）。

## 缓存与成本

- **图片缓存**：按 (通道 + 提示词 + 尺寸) 哈希，重跑不重复出图（`output/cache/`）
- **自动重试**：出图遇通道异常（网络抖动、余额波动等）时自动重试 4 次（退避 3s/8s/15s，2026-10-05 起；此前为 2 次）；若仍失败，任务会带明确错误停下，重新合成只需补出缺失的镜（其余命中缓存）
- **积分余额**：seedream 通道出图消耗 AutoClaw 账号积分；余额不足时接口返回 `balance not enough`（code 560092），需要新出图的分镜会失败（缓存命中的镜不消耗）。可用「月度会员 / 积分加油包」补充（App 内会员积分入口，或让 Agent 代跑下单流程）
- **配音缓存**：按 (通道 + 音色 + 语速 + 文本) 哈希，改文案只重录改过的段落
- **配乐缓存**：按时长分桶（5s 步进）复用
- 编辑重合成路径：`图片复用 → 增量配音 → 重新合成`，通常 1-3 分钟出片；勾选「重新生成意境图」时跳过复用与缓存，全量重出全部画面

## 已知限制（诚实清单）

- `cogview` / `openai` 文本与语音通道按公开文档实现，**未在本机实测**（缺 API Key）；接入时以各平台最新文档为准。
- `siliconflow`（画面通道）已于 2026-10-07 本机实测：Kolors 出图 720×1280 竖版、无平台水印；走 OpenAI 兼容协议（`image_size` 参数 + `images[]` 响应，代码已适配）。
- `seedream` 通道依赖本机 AutoClaw 运行时的本地 token 服务；产物右下角带「AutoClaw AI生成」水印（默认保留，`--crop-watermark` 可裁切）。
- 离线模式下，内置三首之外的诗为「纯朗诵版」（无释义/文案）；这是有意设计的降级路径。
- 成片字幕位置/字号按 1080×1920 调校；其他尺寸请检查 `src/srt.ts` 中的自适应参数。
- 渲染速度：1080×1920 全片 ~80 秒成片约需 2-3 分钟（medium preset，视机器而定）。

## 设计说明（为什么这么做）

- **零运行时依赖**：Node 22 原生跑 TS + 全部核心能力用系统件（FFmpeg、无头浏览器、系统语音）——部署门槛最低，升级通道最多。
- **每道工序独立可换**：通道以配置切换（`.env` / CLI 参数），互不影响，符合路书「每一步都保持完整闭环」的原则。
- **视频动效不靠生成**：意境图 + 运镜（zoompan）先跑通闭环，把视频生成留给「第二步提升质感」按镜头选择性使用，控制成本。
- **缓存即省钱**：所有昂贵产物（AI 图、TTS）都有内容哈希缓存，编辑迭代不重复付费。
